# CyberDuck Landing Page

Static landing page for CyberDuck — Distributed Intelligence Network.

## Deploy to Railway

1. Push this folder to a new GitHub repo
2. Open Railway → New Project → Deploy from GitHub
3. Select the repo → Railway auto-detects and deploys
4. Set a custom domain in Railway settings (optional)

## Files

- `index.html` — Main landing page
- `logo.png` — CyberDuck logo
- `package.json` — serve dependency
- `nixpacks.toml` — Railway build config
